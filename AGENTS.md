# Repository Guidelines

- Preserve the existing Raspberry Pi and live-camera behaviour when changing the
  project.
- Keep detection, OCR, matching, and display logic modular.
- Never commit real licence plates, owner names, student IDs, screenshots,
  secrets, OCR models, or generated user data.
- Run the configured tests before reporting completion.
- Describe this project as an access-decision prototype. Do not claim production
  readiness or physical gate-control capability.
